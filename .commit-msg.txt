feat(article-format)!: 取消默认排版，改为按文体强制选择

不指定 profile 从「静默套用 default」变为「报错退出并列出可选文体」，
文体名写错也从静默回落基线变为报错。此前判不出文体时会兜一套通用规格，
出的成品可能整套版式都不对。

- 原 default 基线独立为正式文体选项 formal-doc（方案/总结/汇报/调研报告/
  说明书等通用正式文章），样式不变
- spec_loader 增加 require 语义与 ProfileNotSpecified / ProfileNotFound
- md2docx / article_style / verify_article_style 三入口统一拦截，
  无 profile 或未知文体均 exit 2
- --list-profiles 输出 12 个行业文体 + formal-doc，不再含 default
- 回归与一致性脚本清理 default 特殊分支

BREAKING CHANGE: 不传 --profile 的调用会直接失败，需显式指定文体。
通用文章请用 --profile formal-doc。

13 个 profile 回归全绿；三入口无 profile / 未知文体均正确 exit 2。
